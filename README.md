# OSA Detection

Deep learning for obstructive sleep apnea event detection from physiological signal data.

This repository contains the research code used to train and evaluate a neural network for detecting obstructive sleep apnea (OSA) events. The project includes the scripts and libraries required for data preparation, model training, and prediction.

This repository corresponds to the research code used for the initial preprint version of the work.

## Related publication

Initial preprint version:
- Gavidia et al., medRxiv, 2023

Final peer-reviewed version:
- Published in **npj Digital Medicine** (2024)  
- https://www.nature.com/articles/s41746-024-01139-z

## Dependencies

This code was tested with:
- Python 3.9.12
- TensorFlow 2.8
- MATLAB R2020a

## Main files

- `main.m`  
  Generates the processed data used for training and testing.

- `train_test.py`  
  Trains the neural network and evaluates predictions.

## Summary

This project focuses on automated detection of obstructive sleep apnea events using deep learning, with the aim of supporting scalable and accurate analysis of sleep-related physiological data.
